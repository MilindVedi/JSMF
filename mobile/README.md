# JSMF Med Prep (mobile)

The Expo (Android + iOS) app for the JSMF PYQ product. Install from the repo root (`npm install`), then `npx expo start` here.

Everything else — environment variables, emulator URLs, what is shared with web through `@jsmf/core`, store-rules decisions and the pre-submission checklist — is in [`docs/mobile/README.md`](../docs/mobile/README.md).
